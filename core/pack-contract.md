# Pack contract

What the engine, the lint and the knowledge in `core/` may assume about any brand pack. Everything
here is a *role*; each pack binds roles to its own values. `core/` and `engine/` speak only in
roles: they never name a colour, a font or a brand.

## tokens.json (DTCG, source of truth)

Aliases use the DTCG form `{group.token}`. Required paths:

| Path | Type | Meaning |
| --- | --- | --- |
| `role.color.ink` | color | Body text on light backgrounds. |
| `role.color.background` | color | Content-slide background. |
| `role.color.accent` | color | Primary brand accent: eyebrows, numerals, rules, markers, the primary chart series. |
| `role.color.highlight` | color | The one active / emphasised element of a slide. Stroke, numeral, icon or arrow, never a large fill. |
| `role.color.muted` | color | Secondary text, arrows and links. |
| `role.color.rule` | color | Hairlines: box outlines, axes, grid rules. |
| `role.color.surface` | color | Quiet fill for boxes and panels. |
| `role.color.wash.*` | color | Signature background washes (`cover`, `summary`, `divider`, `subsection`, `emphasis`). Optional individually. |
| `role.color.series.1` … `n` | color | Quiet ramp for further chart series, after `accent`. At least 2. |
| `role.color.status.positive` / `warning` / `info` | color | Data/status-only colours. Never body text, never decoration. |
| `role.font.display` / `body` / `label` | fontFamily | Display (titles, big numerals), body, labels/eyebrows. |
| `role.fontWeight.display` / `body` / `label` | fontWeight | Matching weights. |
| `role.size.cover_title`, `divider_title`, `title`, `body`, `label`, `caption`, `numeral`, `numeral_xl` | dimension (pt) | Type scale on the slide canvas. |
| `role.stroke.hairline` / `link` / `emphasis` | dimension (pt) | Line weights. |
| `theme.dk1` … `theme.accent6`, `theme.hlink`, `theme.folHlink` | color | What the template's `clrScheme` must contain. |
| `theme.font.major` / `theme.font.minor` | fontFamily | What the template's `fontScheme` must contain. |

## pack.yaml

Validated by `engine/src/calque_engine/schemas/pack.schema.json`. Declares the roles the template
slides play (`cover`, `summary`, `divider`, `subsection`, `closing`, `appendix`, `content`, named
`archetypes`), the slides never to clone, the grid (column edges, title box, body top, footer,
and optionally `grid.source`, the box of the source line under a chart), the font fallback, the
lint rules specific to the pack (single-use colours, voice rules as `slop_rules`, literal
placeholders, `chart_source` to warn on a chart without a source), and the arbitrated theme/token
gaps. `localized_text` translates the template's own lines (a closing "thank you"): keyed by the
line as the template writes it, then by language. A slide cloned from the template shows that
line in the deck language unless the deck sets the shape, and lint exempts it like the original.

`extends: <pack id>` makes the pack a subsidiary of a group pack: it inherits the group's
`voice.md`, `storyline.md`, `exemplar.md` (with its `exemplar/` pages) and `lint.slop_rules`, each
unless it has its own. Its template, tokens and every other key stay its own. The engine merges
them when it loads the pack (`calque_engine.pack`), so lint, build and the `pack://` resources the
agent reads all see the same result.

## template-map.yaml

Generated by the extractor from `template.pptx`, then reviewed. One entry per slide: its shapes
by `shape_id` (kind, bbox in inches, text, font, size, estimated capacity). Review adds slot names
(`slots: {title: 3, body: 186}`) and a description; re-extraction keeps the reviewed keys. On the
`content` slide, the optional slots `eyebrow` and `source` (a footnote placeholder) are filled by
drawn slides, and deleted when the slide has none.
