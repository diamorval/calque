# Calque persona review — 2026-10-09

Four personas used the running app: a fake OIDC IdP, a fake scripted model, and the real server and engine (`apps/web/e2e/serve.ts`). They drove it with Playwright, built and rendered real PPTX files, and read the code where the UI could not reach.

| Persona | Context | Findings |
| --- | --- | --- |
| Consultant × 2 brands (**wins ties**) | Diametral consultant: one Diametral deck, then a client-brand deck (template onboarding → deck → review → export → PowerPoint round trip), web and MCP | C1–C20 |
| Marketing director | Owns the Diametral pack: governance, voice, compliance, approvals | M1–M18 |
| Client self-serve | French industrial group: M365, Entra ID, EU hosting, Mistral / Azure OpenAI | S1–S18 |
| IT / security admin | Same group: security review, deploy, SSO, keys, operations | I1–I17 |

**Ranking:** blockers first, then impact (H/M/L) × effort (S/M/L). Ties go to the consultant persona. **Plan tag:** "in plan" means the implementation plan promises it and it is missing or broken; "not in plan" means it is new.

**Limit:** the model was fake, so this review does not judge the quality of AI-written content. It covers flows, UI, PPTX output, integrations and security.

## What already works

- The Diametral PPTX is solid: native charts and tables, embedded fonts, slide-number fields, 0 lint errors.
- The comment → apply → history → restore → present loop is smooth.
- A simple client template publishes in about 5 s, and team-only pack visibility is enforced.
- SSO with PKCE and HttpOnly cookies works. `/api` and `/mcp` refuse requests without a token. Model admin RBAC works. Model keys are sealed with AES-256-GCM and never returned.

## Where personas disagree

- **Approval and export gates (M9, M18).** Marketing wants them; consultants would be blocked the night before a pitch. Make them opt-in per pack or deck type, and make the export gate soft: warn and record a reason.
- **Preview link (S1).** Consultants need to share with clients, IT needs it locked. Use a signed, expiring, revocable link scoped to one version, not anonymous write.
